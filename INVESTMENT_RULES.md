# Investment rules for Money Master

These are fixed **game-balance assumptions**, not current Indian rates, product offers, forecasts, or guarantees. No live price feed is used. Stock and gold linked products use the same admin-authored or seeded market scenario for every player in a game month. All values are in simulated rupees. Taxes, brokerage, GST, stamp duty, exit-load tax treatment, and actual settlement delays are omitted unless a game fee is stated below.

Players buy products through the existing allocation screen. Month 1 purchases are included in the exact Rs1,00,000 starting budget. Months 2–12 purchases draw from available cash once per month. The backend creates a separate lot for each purchase and applies the monthly return when that month is processed. Partial sales use oldest lots first. Maturities credit cash automatically during the maturity month's processing, before events and the deficit safety net.

| Product | Game return rule | Game costs | Liquidity and game-end treatment |
| --- | --- | --- | --- |
| Bank fixed deposit, 3 months | 6.4% illustrative annual rate, converted to an equivalent monthly compound rate | 2% of the value sold before maturity | Matures after 3 processed game months and returns to cash. Early sale is allowed with the fee. Any lot still active at Month 12 stays in the final portfolio. |
| Treasury bill, 6 months | 6.3% illustrative annual rate, converted to an equivalent monthly compound rate | 1% of value sold before maturity | Matures after 6 processed game months and returns to cash. Early sale is allowed with the fee. This is a simplified fixed-value game instrument, not an auction-priced Indian T-bill. |
| Liquid mutual fund | 5.4% illustrative annual rate converted monthly, plus a shared stock-linked adjustment capped at ±0.10% per month | No separate game exit fee; small shared NAV movement remains possible | Sellable in any open month. Final holdings remain assets. It is not represented as a deposit or guaranteed balance. |
| Arbitrage fund | 5.7% illustrative annual rate converted monthly, plus a stock/gold-spread adjustment capped at ±0.15% per month | 0.02% monthly fee; 0.25% exit fee within the first 3 months | Sellable in any open month. Final holdings remain assets. Spread, fee, and returns are educational approximations. |
| Nifty 50 index fund | Shared stock scenario return | 0.04% monthly fee; 1% exit fee within the first 3 months | Sellable in any open month. Final holdings remain assets. A broad-market label does not prevent losses. |
| Flexi-cap equity fund | 1.25 times the shared stock scenario return | 0.09% monthly fee; 1% exit fee within the first 6 months | Sellable in any open month. Final holdings remain assets. The 1.25 multiplier is an invented game risk setting, not a real fund behavior claim. |
| Balanced advantage fund | 55% shared stock return + 15% shared gold return + 30% of a 5.2% illustrative annual debt return | 0.07% monthly fee; 1% exit fee within the first 3 months | Sellable in any open month. Final holdings remain assets. Its mix can lag in a strong equity rally and can still lose value. |
| Gold ETF | Shared gold scenario return | 0.05% monthly fee; no game exit fee | Sellable in any open month. Final holdings remain assets. This is simulated market exposure, not a gold price promise. |
| Small business / resale venture | Shared business-cycle regime formula; monthly result is capped between -20% and +12% | 0.3% monthly operating cost; 5% exit fee before its 6-month target maturity | Early sale is allowed with the fee. Maturity returns the remaining value to cash. An unmatured Month 12 holding remains a valued asset at game end; it is not forcibly sold. This is a fictional game mechanic. |
| PPF | 7.1% illustrative annual game rate, converted to an equivalent monthly compound rate | No simulated tax benefit or game fee | Locked for the competition. The model records a 180-month maturity and prohibits withdrawal during the 12-month game. Its rate is not a live PPF rate. |
| NPS | 50% shared stock return + 15% shared gold return + 35% of a 5.2% illustrative annual debt return | 0.05% monthly fee | Locked for the competition. The model records a 361-month maturity and prohibits withdrawal during the 12-month game. This does not model real NPS contribution, tax, or exit rules. |

Exit fees are charged against the current value sold, not the original purchase amount. Monthly product fees reduce that month's modeled return. Risk weights feed the existing portfolio risk heuristic; they do not predict volatility or expected return. A product with the largest assumed return is not automatically the best choice because liquidity, fees, lock-in, shared market declines, household expenses, debt and the unchanged Financial Health Score all matter.

The Investment Horizon Lab is a separate illustrative SIP calculation. It does not create assets, transactions or points in the 12-month competition. Its assumed annual rates, contribution timing and omissions are shown beside the result. It excludes taxes, actual product fees and inflation.

## Database installation and rollback

`supabase.sql` is the single repeatable schema installation/upgrade path. The investment portfolio column and transaction updates are part of that canonical file. Apply it only to an isolated staging copy after backup and review; this implementation did not connect to or change hosted data. Do not run the historical `investment_portfolio_migration.sql` after the canonical schema: it replaces transaction functions and can restore older contracts. A rollback should restore the pre-upgrade database backup and the matching application revision; do not drop the portfolio column from a database that has recorded investment lots.
